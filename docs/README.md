## 🔑 核心知识点速览

### 架构设计
- **DDD 分层**: interfaces → application → domain ← infrastructure
- **模块结构**: api / impl / sdk / bootstrap
- **依赖方向**: 严格单向，领域层纯净

### 命名规范
- **数据库对象**: XXXDO
- **聚合根**: XXXAggregate
- **请求对象**: XXXRequest
- **响应对象**: XXXVO

### 技术栈
- **Java**: 25
- **Spring Boot**: 4.0.5
- **Spring Cloud**: 2025.1.0
- **Spring Cloud Alibaba**: 2025.1.0.0
- **MyBatis Plus**: 3.5.15
- **Redisson**: 4.3.1
- **RocketMQ**: 2.3.0
- **Sentinel**: 熔断限流

### 最佳实践
- **轻量化依赖**: mq.compensation 使用 JDBC
- **零存储 Refresh Token**: 利用 JWT 自然过期
- **用户维度在线状态**: 不按设备区分
- **设备标识**: 排除 IP，仅用浏览器特征
- **补偿记录失败必须抛异常**: 确保数据一致性

### 常见问题
- AutoConfiguration.imports 路径错误
- @Value 缺少默认值
- RocketMQTemplate 构造器注入失败
- 循环依赖
- MyBatis Plus 分页无效
- Feign 调用超时
