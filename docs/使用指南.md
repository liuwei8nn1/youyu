## 🎯 不同场景的使用方式

### 场景 1: 我是新加入的开发者

**目标**: 快速了解项目

**步骤**:
1. 阅读 [01-项目知识库总览.md](./01-项目知识库总览.md) - 了解整体架构
2. 浏览 [02-技术栈详解.md](./02-技术栈详解.md) - 熟悉技术栈
3. 查看 [05-快速参考手册.md](./05-快速参考手册.md) - 收藏常用模板
4. 开始编码时参考 [03-开发规范.md](./03-开发规范.md)

**预计时间**: 30-60 分钟

---

### 场景 2: 我要实现一个新功能

**目标**: 编写符合规范的代码

**步骤**:
1. 查看 [05-快速参考手册.md](./05-快速参考手册.md) 中的代码模板
2. 参考 [03-开发规范.md](./03-开发规范.md) 确保命名和结构正确
3. 如涉及性能优化，查看 [04-最佳实践与常见问题.md](./04-最佳实践与常见问题.md)
4. 提交前使用 [03-开发规范.md](./03-开发规范.md) 的 Code Review 清单自查

**推荐模板**:
- DDD 聚合根模板
- Repository 模板
- Application Service 模板
- Controller 模板

---

### 场景 3: 我遇到了一个问题

**目标**: 快速找到解决方案

**步骤**:
1. 在 [04-最佳实践与常见问题.md](./04-最佳实践与常见问题.md) 中搜索问题关键词
2. 查看"常见问题与解决方案"章节
3. 如未找到，查看相关最佳实践章节
4. 如仍未解决，记录解决方案并补充到文档中

**常见问题包括**:
- Spring Boot Starter 自动配置路径错误
- @Value 缺少默认值
- RocketMQTemplate 注入失败
- 循环依赖
- MyBatis Plus 分页无效
- Feign 调用超时

---

### 场景 4: 我要进行 Code Review

**目标**: 确保代码质量

**步骤**:
1. 打开 [03-开发规范.md](./03-开发规范.md)
2. 找到"Code Review 检查清单"章节
3. 逐项检查代码
4. 参考 [04-最佳实践与常见问题.md](./04-最佳实践与常见问题.md) 中的最佳实践

**检查要点**:
- 架构层面（DDD 分层、依赖方向）
- 代码质量（命名、重复代码、单一职责）
- 异常处理
- 性能考虑
- 安全性
- 可维护性

---

### 场景 5: 我要给 AI 助手提供上下文

**目标**: 让 AI 生成符合项目规范的代码

**方式 1: 完整上下文**（推荐用于复杂任务）
```
请阅读以下文档了解 Youyu 项目：
1. md-lingma/01-项目知识库总览.md
2. md-lingma/02-技术栈详解.md
3. md-lingma/03-开发规范.md

然后帮我实现一个[具体功能]，要求：
- 符合 DDD 架构规范
- 使用正确的命名规范
- 包含必要的异常处理
- 遵循最佳实践
```

**方式 2: 快速上下文**（适用于简单任务）
```
请参考 md-lingma/05-快速参考手册.md 中的代码模板，
帮我创建一个[实体名称]的 DDD 实现，包括：
1. 聚合根
2. Repository
3. Application Service
4. Controller
```

**方式 3: 问题解决**（适用于 debugging）
```
我遇到了这个问题：[描述问题]

请参考 md-lingma/04-最佳实践与常见问题.md 
中的"常见问题与解决方案"章节，帮我解决。
```

## 💻 实用技巧

### 技巧 1: 使用搜索功能

在 IDE 或编辑器中使用全局搜索（Ctrl+Shift+F）快速定位：
- 搜索类名：`UserAggregate`
- 搜索注解：`@SentinelResource`
- 搜索配置：`@Value`
- 搜索错误：`ClassNotFoundException`

### 技巧 2: 收藏常用章节

建议在浏览器或编辑器中书签以下章节：
- 05-快速参考手册.md → 代码模板
- 03-开发规范.md → 命名规范
- 04-最佳实践与常见问题.md → 常见问题

### 技巧 3: 复制粘贴模板

从 05-快速参考手册.md 复制模板后：
1. 替换占位符（如 `{EntityName}`）
2. 根据实际需求调整
3. 确保符合 03-开发规范.md 的规范

### 技巧 4: 持续更新

当你发现：
- 新的最佳实践
- 新的常见问题及解决方案
- 新的代码模板

请更新对应文档，帮助团队和其他 AI 助手。

## ❓ FAQ

### Q1: 这些文档多久更新一次？
A: 当项目发生重大变更时更新，建议每次技术栈更新或规范调整后同步更新文档。

### Q2: 我可以修改这些文档吗？
A: 当然可以！欢迎补充新的最佳实践、常见问题和代码模板。

### Q3: 如何分享给其他 AI 助手？
A: 直接分享 `md-lingma/` 目录，或根据需要分享单个文档。推荐使用 README.md 作为入口。

### Q4: 文档太多，记不住怎么办？
A: 不需要记住所有内容。记住 README.md 的位置，需要时查阅即可。常用内容可收藏书签。

### Q5: 可以和项目文档（doc/）一起使用吗？
A: 是的！`md-lingma/` 聚焦于规范和最佳实践，`doc/` 包含更详细的业务文档，两者互补。
