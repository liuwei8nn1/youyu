## DDD 架构规范

### 分层架构

#### 依赖方向
```
interfaces → application → domain ← infrastructure
```

#### 原则
- 严格遵循依赖方向，禁止反向依赖
- 领域层通过 Repository Interface 等抽象契约与基础设施层解耦（依赖反转）
- 领域层禁止依赖基础设施层具体实现类（MyBatis Mapper、RocketMQTemplate 等）
- 领域层允许直接使用 Caffeine、RedisUtil 等标配工具

---

### 1. Interfaces 层（用户接口层）

#### Controller
| 项目 | 说明 |
|------|------|
| **职责** | 接收 HTTP 请求、参数校验（`@Valid`）、响应格式化 |
| **允许** | `@Resource` 注入 ApplicationService |
| **禁止** | ❌ 包含业务逻辑、❌ 直接操作数据库、❌ 调用其他微服务 |

```java
@RestController
@RequestMapping("/api/users")
public class UserController {
    @Resource
    private UserApplicationService userApplicationService;

    @PostMapping
    public Result<UserVO> createUser(@Valid @RequestBody CreateUserRequest request) {
        return Result.success(userApplicationService.createUser(request));
    }
}
```

#### 请求/响应 DTO
- 请求对象：`XXXRequest`，接口层定义，含 `@Valid` 校验注解
- 响应对象：`XXXVO`，接口层定义，不含业务逻辑

---

### 2. Application 层（应用层）

#### 应用服务（ApplicationService）
| 项目 | 说明 |
|------|------|
| **职责** | 协调领域对象完成业务用例、事务控制、参数校验 |
| **允许** | 持有 Repository Interface、调用领域服务、DTO 转换 |
| **禁止** | ❌ 包含核心业务规则、❌ 直接操作数据库 |

```java
@Service
@Transactional
public class UserApplicationService {
    @Resource
    private UserRepository userRepository;
    @Resource
    private UserAssembler assembler;

    public UserVO createUser(CreateUserRequest request) {
        UserAggregate user = UserFactory.create(request);
        userRepository.save(user);
        return assembler.toVO(user);
    }
}
```

#### Assembler / Converter
- 职责：Application 层与外部层之间的对象转换
- 命名：`XXXAssembler`（Spring Bean）或 `XXXConverter`（静态方法）

---

### 3. Domain 层（领域层）- 核心

#### 聚合根（Aggregate Root）
| 项目 | 说明 |
|------|------|
| **职责** | 管理自身一致性边界内的状态，执行业务规则 |
| **允许** | 持有值对象、实体列表，抛出 `DomainException` |
| **禁止** | ❌ 持有 Repository、❌ 依赖 Spring 注解、❌ 依赖基础设施 |

```java
public class OrderAggregate {
    private Long orderId;
    private List<OrderItem> items;
    private Long productId;
    private ShippingAddress address;

    public void markAsPaid() {
        if (status != STATUS_PENDING) {
            throw new DomainException("只有待支付订单才能支付");
        }
        this.status = STATUS_PAID;
    }
}
```

#### 实体（Entity）
| 项目 | 说明 |
|------|------|
| **职责** | 有唯一标识的业务对象，具有生命周期 |
| **区别** | 实体有 ID 可追踪，值对象无 ID 只描述 |

```java
public class OrderItem {
    private Long id;
    private Long productId;
    private Integer quantity;
    private BigDecimal price;
}
```

#### 值对象（Value Object）
| 项目 | 说明 |
|------|------|
| **职责** | 描述性对象，无唯一标识，不可变 |
| **命名** | `Email`、`PhoneNumber`、`Money`、`ShippingAddress` |

```java
public class Email {
    private final String value;

    public Email(String value) {
        if (!isValid(value)) throw new DomainException("无效的邮箱地址");
        this.value = value;
    }
}
```

#### 领域服务（Domain Service）
| 项目 | 说明 |
|------|------|
| **职责** | 跨聚合协调、依赖外部资源的业务逻辑 |
| **允许** | 持有 Repository 接口、使用 Caffeine/RedisUtil |
| **禁止** | ❌ 依赖 MyBatis Mapper、JdbcTemplate、RocketMQTemplate 等实现类 |

```java
@Service
@RequiredArgsConstructor
public class SeckillStockDomainService {
    private final SeckillActivityRepository activityRepository;
    private final Cache<Long, SeckillActivityAggregate> localCache = Caffeine.newBuilder().build();

    public Long deductStockAndRecordPurchase(Long productId, Long userId, Integer quantity, Integer limit) {
        // Lua 脚本原子扣减库存
        Long remaining = RedisUtil.executeLuaScript(SCRIPT, keys, args, Long.class);
        if (remaining == null || remaining == -1) throw new DomainException("秒杀失败，库存不足");
        return remaining;
    }
}
```

#### Repository 接口
| 项目 | 说明 |
|------|------|
| **职责** | 定义聚合根的持久化契约 |
| **位置** | `domain/repository/` 包下，纯接口 |
| **实现** | 在 Infrastructure 层完成 |

```java
public interface OrderRepository {
    OrderAggregate findById(Long id);
    void save(OrderAggregate order);
}
```

#### 领域异常（DomainException）
| 项目 | 说明 |
|------|------|
| **基类** | `com.youyu.common.exception.DomainException` |
| **构造** | `new DomainException("消息")` 或 `new DomainException("错误码", "消息")` |
| **处理** | `GlobalExceptionHandler` 统一转 `Result.error(code, message)` |
| **使用** | 聚合根、领域服务中直接抛出 |

```java
throw new DomainException("商品不存在");
throw new DomainException("400", "余额不足");  // 自定义错误码
```

#### 领域事件（Domain Event）
| 项目 | 说明 |
|------|------|
| **职责** | 状态变更后通知其他聚合/服务 |
| **方式** | 聚合内记录 → 应用层订阅 → MQ/Spring Event 异步发送 |

---

### 聚合设计原则

| 原则 | 说明 | 反例 |
|------|------|------|
| **聚合要小** | 只包含强一致性对象 | 把订单 + 用户 + 商品全塞一个聚合 |
| **通过 ID 引用** | 不直接持有其他聚合对象 | `OrderAggregate.user` 直接引用 UserAggregate |
| **一个事务一个聚合** | 事务边界 = 聚合边界 | 一个事务改多个聚合 |

```java
// ✅ 正确
public class OrderAggregate {
    private List<OrderItem> items;    // 订单项（强一致）
    private Long userId;              // 只引 ID
    private Long productId;           // 只引 ID
    private ShippingAddress address;  // 值对象快照
}
```

### 领域服务 vs 聚合方法

| 场景 | 用哪个 | 示例 |
|------|--------|------|
| 只涉及聚合内部状态变更 | **聚合方法** | `order.markAsPaid()`、`activity.assertActive()` |
| 涉及多个聚合协调 | **领域服务** | 扣库存 + 记录购买（Lua 脚本） |
| 需要访问 Repository 或缓存 | **领域服务** | 查活动 + 判时间 + 扣库存 |

### 领域事件

```
聚合方法内发布事件 → 应用层订阅 → ReliableMessageProducer 发送 MQ
```

```java
public class OrderAggregate {
    public void pay() {
        this.status = OrderStatus.PAID;
        registerEvent(new OrderPaidEvent(this.orderId));
    }
}
```

MQ 框架已封装在 `youyu-framework`，通过 `ReliableMessageProducer` 统一发送。

##### 4. Infrastructure 层（基础设施层）
**职责**:
- 实现 Repository 接口
- 数据库访问（MyBatis Plus）
- 缓存操作（Redis）
- 消息队列操作
- 第三方服务调用

**示例**:
```java
@Repository
public class UserRepositoryImpl implements UserRepository {
    
    @Resource
    private UserMapper userMapper;
    
    @Override
    public UserAggregate findById(UserId id) {
        UserDO userDO = userMapper.selectById(id.getValue());
        return UserConverter.toAggregate(userDO);
    }
    
    @Override
    public void save(UserAggregate user) {
        UserDO userDO = UserConverter.toDO(user);
        userMapper.insertOrUpdate(userDO);
    }
}
```

## 模块职责划分

### Framework vs Starter

#### Framework 模块
**职责**:
- 提供核心功能实现
- 工厂类（如 WarnChannelFactory）
- 工具类和通用组件
- 可被多个 Starter 引用

**示例结构**:
```
youyu-framework/
├── warn/
│   ├── channel/
│   │   └── WarnChannelFactory.java  // 工厂类在这里
│   └── service/
├── cache/
├── anti-shake/
└── mq/
    └── compensation/  // 使用 JdbcTemplate
```

#### Starter 模块
**职责**:
- 自动配置（AutoConfiguration）
- Bean 创建和管理
- 条件装配（@ConditionalOnProperty）
- 对外提供开箱即用的能力

**示例结构**:
```
youyu-starter/
├── src/main/resources/
│   └── META-INF/
│       └── spring/
│           └── org.springframework.boot.autoconfigure.AutoConfiguration.imports
└── src/main/java/
    └── com.youyu.starter.autoconfigure/
        ├── web/
        ├── security/
        ├── data/
        └── logging/
```

**原则**: 
- 工厂类放在 framework
- 自动配置放在 starter
- starter 依赖 framework

### API / Impl / SDK / Bootstrap

#### API 模块
**职责**:
- 接口定义
- DTO 定义
- Feign Client 定义

**示例**:
```java
// Feign Client
@FeignClient(name = "user-service")
public interface UserFeignClient {
    @GetMapping("/api/users/{id}")
    Result<UserVO> getUserById(@PathVariable Long id);
}
```

#### Impl 模块
**职责**:
- 接口实现
- 业务逻辑
- DDD 四层架构实现

#### SDK 模块
**职责**:
- 封装 API 调用
- 提供便捷的客户端
- 隐藏底层实现细节

**示例**:
```java
@Component
public class UserSdkClient {
    
    @Autowired
    private UserFeignClient userFeignClient;
    
    public UserVO getUser(Long id) {
        Result<UserVO> result = userFeignClient.getUserById(id);
        return result.getData();
    }
}
```

#### Bootstrap 模块
**职责**:
- 启动类
- 配置文件
- 依赖组装

## 异常处理规范

### 异常分类

#### 1. 领域异常（DomainException）
**用途**: 业务规则违反（位于 `youyu-common`，各模块共享）

```java
// 定义位置：youyu-common
public class DomainException extends RuntimeException {
    public DomainException(String message) { super(message); }
}

// 使用 - 在聚合根或领域服务中直接抛出
public void assertActive() {
    if (isEnded()) throw new DomainException("秒杀活动已结束");
    if (isNotStarted()) throw new DomainException("秒杀活动未开始");
}
```

#### 2. 应用异常（ApplicationException）
**用途**: 应用层错误

```java
public class ApplicationException extends RuntimeException {
    public ApplicationException(String message) {
        super(message);
    }
}
```

#### 3. 基础设施异常（InfrastructureException）
**用途**: 技术层面错误

```java
public class InfrastructureException extends RuntimeException {
    public InfrastructureException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

### 全局异常处理

全局异常处理器位于 `youyu-framework/.../GlobalExceptionHandler.java`，已注册为 `@RestControllerAdvice`，自动对所有 Controller 生效。

```java
// DomainException → 400 级别错误（业务规则违反）
@ExceptionHandler(DomainException.class)
public Result<Object> handleDomainException(DomainException ex) {
    log.warn("领域异常: {}", ex.getMessage());
    return Result.error(ex.getCode(), ex.getMessage());
}

// 通用异常 → 500 级别错误（未知系统异常兜底）
@ExceptionHandler(Exception.class)
public Result<Object> handleGenericException(Exception ex) {
    // ...
    return Result.error("系统繁忙，请稍后重试");
}
```

### 补偿记录保存失败必须抛出异常

**原则**: 补偿表保存失败时必须抛出异常，让业务层感知

**原因**:
- 确保数据一致性
- 避免静默失败导致补偿机制失效
- 让上层业务能够正确处理异常情况

**示例**:
```java
public void saveCompensationRecord(CompensationRecord record) {
    int rows = jdbcTemplate.update(SQL, params);
    if (rows == 0) {
        // ❌ 错误 - 不要吞掉异常
        // log.error("保存补偿记录失败");
        
        // ✅ 正确 - 抛出异常
        throw new InfrastructureException("保存补偿记录失败");
    }
}
```

## 安全规范

### 验签规范

#### 轻量级验签（网关层）
**签名计算范围**: Header + Path（**不包含 Body**）

**原因**:
- 减少前端计算压力
- 提高请求处理速度
- 基于 Header+Path 的验签已足够安全

**示例**:
```java
// 签名生成
String sign = MD5(appKey + path + timestamp + nonce + secret);

// 签名验证
String expectedSign = MD5(appKey + path + timestamp + nonce + secret);
if (!sign.equals(expectedSign)) {
    throw new SecurityException("签名验证失败");
}
```

#### 分层安全架构
- **外部网关**: 负责通用安全（轻量级验签）
- **业务微服务**: 负责核心业务安全（如需可对 Body 全量验签）

### JWT Token 规范

#### Refresh Token 滚动刷新
**方案**: 轻量级零存储

**实现**:
- 不单独存储 Refresh Token
- 利用 JWT 自然过期机制
- 滚动刷新延长会话有效期

```java
public TokenPair refreshToken(String oldRefreshToken) {
    // 验证旧 Refresh Token
    Claims claims = jwtUtil.parseToken(oldRefreshToken);
    
    // 生成新的 Token 对
    String newAccessToken = jwtUtil.generateAccessToken(claims);
    String newRefreshToken = jwtUtil.generateRefreshToken(claims);
    
    return new TokenPair(newAccessToken, newRefreshToken);
}
```

### 设备标识规范

#### 禁止使用 IP 地址
**原因**:
1. 动态 IP：移动网络、DHCP 环境下 IP 频繁变化
2. 代理/VPN：用户使用代理或 VPN 会导致 IP 变化
3. 网络切换：WiFi 与 4G 切换时 IP 也会改变

#### 正确的设备标识
仅使用浏览器/设备本身的固有特征：

```java
// ✅ 正确
String deviceUniqueId = HashUtil.md5(
    userAgent + 
    secChUa + 
    secChUaPlatform + 
    secChUaMobile
);

// ❌ 错误
String deviceUniqueId = HashUtil.md5(ipAddress + userAgent);
```

## 配置规范

### 环境配置分离

#### 配置文件结构
```
src/main/resources/
├── application.yml          # 主配置
```

### 本地开发优化

#### 禁用消费者加速启动
```yaml
# application-dev.yml
rocketmq:
  consumer:
    enabled: false  # 本地开发禁用消费者
```

或使用注解：
```java
@Profile("!dev")
```

```java
// ❌ 错误 - 缺少默认值，启动可能失败
@Value("${config.property}")

// ✅ 正确 - 设置默认值
@Value("${config.property:default_value}")
private String property;
```
